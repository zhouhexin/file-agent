## 怎样人工判定

1. 在Excel“问题”页按文件ID确定范围，从“文件清单”打开原件。每题有单独完整源路径，同名文件不能混选。
2. 核对原文后，在“人工判定”页填写三个Gold 0/1、理由、标注者和复核者；有疑问保留需仲裁，冻结后再计分。
3. 自行上传所需原文件、等待解析与索引完成，再仅复制题干测试；不要把参考答案或完整工作簿一并当作证据上传。
4. 保存同次运行ID及shadow日志，按实际进入评估器的证据包核对标签。答案漏项、解析漏项、检索漏召回与评估误判分别记录。
5. 从这40题选择合适案例迁入正式60条模板。它们是选材候选，并未代替原模板，R编号也不表示已分配到N/M/C/O组。

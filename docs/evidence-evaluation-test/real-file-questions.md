早先“按句式强制覆盖 LLM 分支”的修复已撤回，最终规则为：

1. 正常自然语言文件问答先调用 LLM，由模型声明业务意图、检索描述和主题条件。
   普通事实问题不再被确定性预检直接截走；问号和来源句式也不能强制覆盖模型的搜索/普通对话选择。
2. 后端把 `managed_query` 和 `file_search_plan` 原样传递给 `hybrid-search`，原始完整问题
   单独保留给后续证据回答。没有精简查询、但有结构化计划时，仍按结构化主题执行，不能丢掉它。
3. 权限、当前文件版本、Tool 白名单、参数、证据相关性和高风险操作确认继续由后端校验。
   没有附件时，真实文件范围须来自检索观察；有后端附件且模型声明问答时，不再要求文本必须含疑问词。
4. 仅模型关闭或规划失败后，确定性 Planner 才按有限明确来源句式拆分检索描述，执行只读发现。
   该兜底不执行文件写操作，也不能把未验证候选当作回答证据。

# WorkBuddy 提示词维护教师成果资助余额表

## 需求与保留范围

用户可通过本轮明确提示词，对已发布新版余额表中已有教师的个人使用登记新增、修改、删除，也可调整该教师的科研成果资助金额或其他资助金额。服务端按个人明细重新计算总支出和余额，重建个人页与首页，并发布同名新版本。现有图片 OCR 首次生成与追加、成果明细表刷新、下载 Excel 手工回传均保留原入口和校验。

后续补充：手写姓名 OCR 不准确时，用户还可明确指定“当前旧姓名 → 正确新姓名”，只更正已发布余额表中的同一位教师。此更正沿用上述提示词预览与发布入口，不改动原始图片或来源成果明细表。

个人页左下方的“其他资助金额”在手工回传时是输入值；服务端从个人页读取、更新首页 D 列，并重新计算两处剩余金额。没有个人页的教师仍留在首页，可通过提示词调整其资助金额；不为了金额修改创建空白个人页。

## 受控操作

1. `funding_usage_prompt_target` 只读当前已发布的完整文件名、版本、哈希、revision、教师和个人登记稳定行 ID。仅支持新版个人明细驱动的余额表；旧版走原有回传规则。教师姓名或登记不唯一时由用户明确选定，不凭描述猜行。
2. `funding_usage_prompt_preview` 接受用户本轮原话、冻结版本和结构化操作。登记操作为 `ADD/UPDATE/DELETE`：新增需已有教师和登记原文，可指定插入位置；修改、删除需稳定行 ID 和姓名。资助金额只允许 `research_total/other_total`，非负且最多两位小数。总支出和剩余金额均由服务端计算，不接受直接输入。金额不明确的新登记保持待核对，相关总支出和余额留空。
3. 预览读取并核对已发布文件与冻结行、资助金额、首页汇总完全一致；同一行不能在一次请求中重复修改或删除。返回每项修改前后、增改删数量、受影响教师的新汇总和指纹。不产生文件版本。
4. `funding_usage_prompt_publish` 只接受与预览一致的请求和当前版本。按个人页重新编号，重算并发布同名不可变版本；请求键幂等，版本变化或无实际差异则拒绝。新增登记标记 `USER_PROMPT`，不伪装成图片 OCR；删除撤销活跃去重记录并保留删除审计。新版本仍可继续图片追加和手工回传。

### 手写姓名更正

- 请求增加可选 `name_edits:[{old_name,new_name}]`。`old_name` 必须与当前首页姓名完全一致；`new_name` 须为非空、无前后空格、长度不超过 31 且能用作 Excel 工作表名。新姓名与其他已有教师相同或仅空格不同、同名无变化、同次重复更名或姓名不明确时拒绝，不自动合并两名教师。
- 一次请求可只更名，也可同时修改登记或金额；同次 `row_edits`、`total_edits` 使用更名前的姓名。预览返回旧名、新名、更名人数和更正后的人员金额。发布校验冻结版本和预览指纹，保留幂等语义。
- 同一次发布更新首页姓名、个人页工作表名、资金映射、个人登记归属、来源登记的当前姓名、有序人员名单和数据集首页行；教师首页稳定行 ID、个人登记稳定行 ID 保持不变。没有登记的人仍只在首页。金额不因更名单独改变；如同次修改金额则按现有规则重算。
- 原始图片中的 OCR 姓名引文、来源文件和历史版本保持原样，更名记录保存在新版本审计中。后续图片若再次 OCR 为旧误识姓名，不能静默当作新教师追加，应先核对归属。

## 接口与审计

- API：`POST /api/funding-usage/prompt/target`、`/prompt/preview`、`/prompt/publish`。
- MCP：同名的 `funding_usage_prompt_target/preview/publish` 固定白名单工具。写入仍经过现有 `execute_dataset_write`，生成 ToolInvocation、ChangeSet、ChangeItem，并使用现有版本发布协调器。
- 版本策略保存操作摘要、用户原话、请求键和来源记录；不新增数据库表，不覆盖旧版本。图片和手工回传的原有来源仍保留。
- 插件技能只负责把用户指令转换成受限参数、核对预览和回执，不能直接写本地 Excel 或调用任意 API。

## 验收

- 同一请求新增登记、修改旧登记和设置其他资助金额后，个人页及首页总支出、其他资助和余额一致；重复发布只返回同一版本。
- 删除登记后重新编号、撤销活跃来源并重算；旧版本与删除审计保留。过期版本、错人行 ID、重复操作和不明确金额不能发布。
- 下载新版文件后在个人页修改其他资助金额并回传，首页 D/F 列与个人页左下方同步；原有图片追加、来源表刷新和其他 Excel 回传回归测试继续通过。
- 更名后首页和个人页使用新姓名，资助与登记行归属一致；无登记教师更名不会新建空白个人页。旧 OCR 引文和旧版本仍可追溯；新姓名重名、非法工作表名与过期版本被拦截。更名后的 Excel 仍能手工回传。

本轮实现沿用既有余额表数据结构；没有数据库迁移。教师姓名更正需同时更新 API、客户端 MCP 至 `0.1.4`、WorkBuddy 插件至 `0.1.90`；只替换插件或只替换 MCP 都不能完成更名。

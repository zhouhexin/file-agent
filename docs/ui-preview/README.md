本版规则：分类反馈收进分类标签交互；首次归档允许对工作副本自动标准化命名；命名证据不足时保留原名；高风险后续操作继续通过确认计划处理。

`receipt-gallery.html` 补充展示搜索、证据回答、结构化识别、明确改名完成、澄清选择、重复文件、回收站恢复、目录列表、处理中、部分失败、无结果和失败等主要前端返回状态。

当前命名预览已收敛为两种：首次归档的命名结果包含在“文件整理 / 分类树”中；“明确改名完成”只对应用户明确提出将一个文件重命名为另一个名称后的成功回执。

WorkBuddy 风格预览保留了 File Agent 原有的蓝色主色、绿色成功、琥珀色待留意和红色失败状态，不采用纯黑白视觉。

分类整理结果继续使用树形结构；WorkBuddy 风格只改变聊天流、排版和外围容器，不改变分类目录的层级表达。

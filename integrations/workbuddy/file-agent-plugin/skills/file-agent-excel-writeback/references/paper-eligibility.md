# 通用 Excel 论文筛选与证据

本规则仅在用户本轮提示词明确要求论文“一作 / 第一作者 / 导师一作”等资格、且任务设置 `manifest.paper_filter=FIRST_AUTHOR_PUBLISHED` 时适用。未提这一条件时沿用通用 Excel 原来的论文读取方式。启用后逐篇先判断作者，再排除明确标为小修或投递中的论文；其余按本次填表口径视为已发表。只依据本轮已读取的正式原文，不用文件名或模型常识补作者证据。

| 候选情况 | 处理 |
| --- | --- |
| 申请人列在作者首位，或原文明确写申请人“本人一作 / 学生一作” | 填写，`first_author_kind=APPLICANT`；学生一作不核对导师 |
| 该篇明确写“导师一作”，申请人属于该篇成果；简历中该姓名为导师且未标为硕士导师 | 填写，`first_author_kind=PHD_ADVISOR`；“导师：姓名”即按博士导师处理 |
| 导师明确标为硕士导师，或文章没有写“导师一作” | 不使用导师一作资格；若申请人也非本人/学生一作则排除 |
| 仅通讯作者、普通第二作者，且没有学生一作标注 | 排除 |
| 明确写“小修”“投稿中”“在投”“投递中”“审稿中” | 排除；这些状态属于本次约定的投递中或小修 |
| `Early Access`、只有刊名、缺少年份卷期页，且未写上述排除状态 | 按本次口径收录，不额外索要发表证明 |

`paper_checks` 与论文题目 `fragments` 一一对应。每项须提供申请人姓名引文、本人一作/学生一作/导师一作引文；导师一作额外提供该姓名与申请人的导师关系引文。只有明确标为导师一作时才核对导师；若导师关系引文把该姓名写成硕士导师，则不能按博士导师收录。`publication_evidence` 可省略，不要求发表状态或卷期页的正面证明；若提供状态引文，须属于同一篇。提交前对照该篇原文查明是否写了小修或投递中，不从相邻论文借用状态。

筛选一次后，将同一合格论文顺序用于题目、刊物、作者角色、收录等所有相关列。每篇的题目片段保留原文，展示层按顺序编号。无法取得作者资格证据时该篇不填，不生成虚假的一作或导师身份。

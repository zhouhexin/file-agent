# 图片使用登记到新 Excel 的字段规则

## 输入范围

旧 Excel 只读 `汇总` 工作表中表头为 `姓名`、`资助总额（元）` 的两列；前后空白可去除，姓名不模糊匹配。个人工作表只供参考样式。图片印刷姓名用于匹配，右侧手写使用登记用于支出；印刷金额列不能作为支出，也不能用来填旧表总额。

## 金额判断

`CONFIRMED_SPEND`：登记文字能明确说明该金额已使用。通常每条引文只含一个正数金额（可有人民币符号、千分位和“元”，小数最多两位），多个支出分别引证；同一个数字不能扣两次。明确的加法式可整式引用，服务端逐项解析求和；不能把整式和其中的加数重复引用。

加法式示例：OCR 原文 `269+6560+2030.+3885+17250`，五个加数为 `269`、`6560`、`2030`、`3885`、`17250`，合计 `29994.00` 元。`2030.` 中的孤立点只在后面紧跟加号时视作标点，不作为小数部分；若逐项引用，只引用 `2030` 的真实 OCR 子串。仅接受正金额用 `+` 或 `＋` 相连，不接受减法、区间、等号后的重报数或归属不清的数字。OCR 算式必须原样保存在登记原文中；有涂改或运算含义不清时标记待核对，不推断金额。

`EXCLUDED`：日期、序号、签名、票据号、余额、划掉且已有明确替代的旧数、印刷预算金额等。说明排除理由。

`UNCERTAIN`：字迹不清、涂改后最终值不明、退回/冲销方向不明、边注无法确定所属人员、疑似重复付款。此人使用金额与余额留空，回执给出对应文字和图片位置；不为追求填满而重复全图 OCR。

没有登记且确认确实为空，或手写原文明说“未使用/未支出”时，才能用 `no_usage=true`，使用额为 `0.00`；后者保留原文并把其中其他数字逐项标成 `EXCLUDED`。有登记文字但没有可确定金额时，不把它解释为零。金额用十进制计算，公式为 `旧表该人资助总额 - 该人全部确认手写支出之和`；不按年度和成果条目分组。

后续每条新增登记单独占汇总页一行，金额只表示本条支出。余额从该人上一条已发布且可信的余额减去本条支出；金额未确认时本条及后续余额留空，用户回传补全后再按行顺序重算。相同图片版本及登记引文不得重复扣款。日期待核对不阻断已确认金额的扣减。

## 生成表格

新 Excel 包含 `使用登记汇总` 和各人员工作表。汇总列为 `序号 / 姓名 / 使用登记原文 / 日期 / 本次使用金额合计（元） / 扣减后余额（元） / 核对状态`。日期从该人的使用登记引文提取完整年月日；只有月日时仅用图片 OCR 中可唯一确定的年份补齐，多个日期逐行列出。能看到日期线索但年份冲突、日期无效或 OCR 不清时，日期格写 `待核对：原始片段（原因）`，状态格追加 `日期待核对`；完全没有日期线索才留空。旧表资助总额只在服务端计算，不写入新表任何列、隐藏列或批注。姓名未在旧表找到、旧表同名多行或总额无效时，登记照写，余额空着并说明。若扣减后为负，保留负数并标为可能超额。生成文件与旧表分开发布，原件不覆盖。

用户下载并核对后，只需改首个汇总页已有行 C–G；回传时服务器按首表重建个人页。A/B、表头、行顺序和 Sheet 名称不能改。F 人工更正需要在 G 写明原因。新增登记不通过手工回传添加行。

# 图片使用登记到新 Excel 的字段规则

## 输入范围

新表的人员名单以旧表 `汇总` 中所有真实教师姓名为基础，保持旧表顺序；表尾“总计 / 50 人 / 合计金额”等统计行必须排除，不能把人数文字当姓名。图片出现而旧表没有的姓名排在后面，资助金额待核对。旧表有姓名但图片无该人记录时，不构造虚假的图片引文或 `no_usage` 登记；该人只在首页汇总，不建立空白个人页，总支出为 `0.00`，有效资助总额直接成为剩余总资助金额。旧表同名多行或资助总额无效时，不合并金额，金额与余额留空待核对。

旧 Excel 只读 `汇总` 工作表中表头为 `姓名`、`资助总额（元）` 的两列；前后空白可去除，姓名不模糊匹配。个人工作表只供参考样式。图片印刷姓名用于匹配，右侧手写使用登记用于支出；印刷金额列不能作为支出，也不能用来填旧表总额。

## 金额判断

`CONFIRMED_SPEND`：登记文字能明确说明该金额已使用。通常每条引文只含一个正数金额（可有人民币符号、千分位和“元”，小数最多两位），多个支出分别引证；同一个数字不能扣两次。明确的加法式可整式引用，服务端逐项解析求和；不能把整式和其中的加数重复引用。

加法式示例：OCR 原文 `269+6560+2030.+3885+17250`，五个加数为 `269`、`6560`、`2030`、`3885`、`17250`，合计 `29994.00` 元。`2030.` 中的孤立点只在后面紧跟加号时视作标点，不作为小数部分；若逐项引用，只引用 `2030` 的真实 OCR 子串。仅接受正金额用 `+` 或 `＋` 相连，不接受减法、区间、等号后的重报数或归属不清的数字。OCR 算式必须原样保存在登记原文中；有涂改或运算含义不清时标记待核对，不推断金额。

`EXCLUDED`：日期、序号、签名、票据号、余额、划掉且已有明确替代的旧数、印刷预算金额等。说明排除理由。

`UNCERTAIN`：字迹不清、涂改后最终值不明、退回/冲销方向不明、边注无法确定所属人员、疑似重复付款。此人使用金额与余额留空，回执给出对应文字和图片位置；不为追求填满而重复全图 OCR。

没有登记且确认确实为空，或手写原文明说“未使用/未支出”时，才能用 `no_usage=true`，使用额为 `0.00`；后者保留原文并把其中其他数字逐项标成 `EXCLUDED`。有登记文字但没有可确定金额时，不把它解释为零。金额用十进制计算，公式为 `科研成果资助金额 + 已填写的其他资助金额 - 该人全部确认手写支出之和`；其他资助金额留空时暂按零参与计算，不按年度和成果条目分组。

后续每条新增登记单独占该人的个人明细页一行，金额只表示本条支出。首页按人汇总所有已确认支出。金额未确认时该人总支出与余额留空，用户回传补全后再重算。相同图片版本及登记引文不得重复扣款。日期待核对不阻断已确认金额的扣减。

## 生成表格

旧表里的每位教师都占首页一行；只有存在登记明细时才创建个人工作表。后续追加和人工回传同样保留没有登记的教师在首页；个人明细发生变化时，首页金额按同一口径重新计算。删除某人最后一条登记后，下一版不再生成其空白个人页，后续首次追加登记时重新建立。

新 Excel 包含 `使用登记汇总` 和各人员工作表。首页列为 `序号 / 姓名 / 总科研成果资助金额 / 其他资助金额（院优青、专委、其他资助） / 总支出 / 剩余总资助金额`，每人只占一行。个人页列为 `序号 / 使用登记原文 / 日期 / 确认使用金额（元） / 核对说明`，逐笔登记序号按该人从 1 开始。明细下方左侧列出首页的四个金额字段。日期从该人的使用登记引文提取完整年月日；只有月日时仅用图片 OCR 中可唯一确定的年份补齐，多个日期逐行列出。能看到日期线索但年份冲突、日期无效或 OCR 不清时，日期格写 `待核对：原始片段（原因）`，核对说明追加 `日期待核对`；完全没有日期线索才留空。旧表的资助总额用于填写新表的“总科研成果资助金额”；旧表没有其他资助金额来源时该格留空，供用户在个人页核对后填写。姓名未在旧表找到、旧表同名多行或总额无效时，登记照写，金额与余额留空并说明。若扣减后为负，保留负数并标为可能超额。生成文件与旧表分开发布，原件不覆盖。

用户下载并核对后，修改对应个人页的登记明细或左下方资助金额；回传时服务器按个人页重算并更新首页。已有明细序号和顺序、表头、汇总标签及 Sheet 名称不能改；新增明细的 A 列序号留空。首页金额由服务器生成，不直接手工改首页。已发布的旧版首表逐笔登记文件仍走旧版回传规则。

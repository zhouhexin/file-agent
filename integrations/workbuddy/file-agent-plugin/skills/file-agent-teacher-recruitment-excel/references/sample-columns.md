# 教师引进汇总表样本列路由

此表只供核对 `西安理工大学教师引进考察汇总表.xlsx` 样本。执行时必须重新读取**本轮上传或已发布当前版本**的实际工作簿、工作表和合并表头；表结构变了就按新表重新定位。

| 物理列 | 样本完整含义 | 填写边界 |
| --- | --- | --- |
| A | 序号 | 由目标表已有序号续排；空表从 1 开始。 |
| B | 学院 | 只取材料明确的学院名称。 |
| C | 拟补充学科 | 无明确拟补充学科时留空。 |
| D | 拟补充系所 | 无明确拟补充系所时留空。 |
| E | 姓名 | 必须来自正文或真实单元格，不能从文件名抄。 |
| F | 性别 | 只取材料明确值。 |
| G | 年龄 | 无明确年龄或授权计算规则时留空。 |
| H | 政治面貌 | 只取材料明确值。 |
| I | 各阶段毕业时间、院校及专业 | 保持阶段与学校、专业对应。 |
| J–L | 发表论文：题目、刊号/刊物及本人角色、收录/引用及 IF | 同篇论文的三列顺序对应，不拼错不同论文。 |
| M–O | 项目：立项号及名称、级别及本人角色、完成情况 | 同一项目的三列顺序对应。 |
| P | 专利、软件著作权、获奖等 | 只取有真实材料证据的项目。 |
| Q | 学院推荐意见 | 按叶标题找意见，不把上层“引进方式”当作值。 |
| R | 是否符合按照引进条件 | 无明确结论或授权规则时留空。 |
| S | 身份证号 | 仅在可信来源明确给出且用户任务需要此列时写入；回执避免重复展示完整号码。 |
| T | 电话号码 | 仅在可信来源明确给出且用户任务需要此列时写入；回执避免重复展示完整号码。 |

样本只有“应届”工作表，第 3–4 行是合并表头，第 5 行有样式但无值，第 6 行 O6 已有 `.`。此 `.` 是原有内容，绝不能被当作待写空格覆盖。

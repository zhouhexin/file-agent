# 教学科研型教授模板 A–I 与 L 来源路由

本参考仅用于已核对为“申报人员业绩汇总—教学科研型教授”同版式的目标表，以及包含 B–I 候选字段或“任现职以来的考核情况”的评审 PDF 或 Word。页码是 PDF 从 1 开始的物理页号。先核对本轮目标 Excel 的真实物理列和 PDF 版式；不同 PDF 版式必须由服务端建立新的受控范围，不自动扫描全文。Word 的字段从真实正文段落或表格定位，不套用 PDF 页码。

B–I 是可填写的列范围，不要求八列都有值。每列只在本来源有可核验证据时填写；未找到填 `SOURCE_FIELD_NOT_FOUND`，有栏目但文字无法辨认填 `OCR_UNREADABLE`。缺失列不补猜、不复读整份 PDF，Excel 单元格留空，并在逐文件回执列明原因。

| 列 | 目标含义 | 本参考 PDF 候选区域 | 校验要点 |
| --- | --- | --- | --- |
| A | 序号 | 无 PDF 来源 | 沿用目标行预置序号或受控行规则。 |
| B | 学院 | 第 1 页封面“单位”；第 3 页基本情况 | 引文可保留字段标签，例如“单位 计算机科学与工程学院”；`value`、候选 `raw_text` 和写入 Excel 的值只能是空格后的“计算机科学与工程学院”。不从文件名猜测。 |
| C | 姓名 | 第 1 页封面“姓名”；第 3 页基本情况 | 两处结果不一致时不自行选值。 |
| D | 出生年月 | 第 3 页基本情况 | 保留来源的年月精度。 |
| E | 工作时间 | 第 3 页基本情况“参加工作时间” | 不与任现职时间混用；具体字值由 OCR 识别。 |
| F | 职称 | 第 3 页基本情况“何年何月取得专业技术职务” | 取现任职称，不把申报资格当现任职称。 |
| G | 职称取得时间 | 第 3 页与 F 同一职称行 | 与 F 配对。 |
| H | 学历 | 第 3 页学历表 | 按 Excel 标题选择学历，不将学位自动替换成学历。 |
| I | 学历取得时间 | 第 3 页与 H 同一学历行 | 与 H 配对。 |
| L | 考核优秀情况 | 仅物理第 25 页服务端冻结的 `annual_review` 区域 | 只取明确写有“考核优秀”的四位年度，升序去重，用 `、` 连接；合格、称职等年度排除。第 25 页不存在、没有真实考核栏目或文字无法辨认时留空并标记原因；不搜索其他页。 |

服务端 v4 PDF 任务仍以 B–I、L 为目标。B–I 使用第 1、3 页冻结区域；L 仅冻结物理第 25 页的受控裁剪图。页数不足 25 时直接 `NOT_FOUND`；第 25 页裁剪图缺少真实“任现职以来的考核情况”正文栏目时，客户端拒绝该区域，服务端转为 `NOT_FOUND`，不向前寻找。25 页版式仍须核对实际裁剪图，错误裁剪不能填充 L。Word 使用已归档完整正文中的真实 `source_unit_id`、逐列短引文与字符范围；扫描图片若未形成可核验文字则停止该文件。J、K、M–AA 无字段候选、无审批/资格判断；PDF 不作全文提取或索引。

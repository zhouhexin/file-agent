# 教学科研型教授模板 A–I 来源路由

本参考仅用于已核对为“申报人员业绩汇总—教学科研型教授”同版式的目标表，以及能提供同样 B–I 字段的评审 PDF 或 Word。页码是 PDF 从 1 开始的物理页号。先核对本轮目标 Excel 的真实物理列和 PDF 版式；不同 PDF 版式必须由服务端建立新的受控范围，不自动扫描全文。Word 的字段从真实正文段落或表格定位，不套用 PDF 页码。

| 列 | 目标含义 | 本参考 PDF 候选区域 | 校验要点 |
| --- | --- | --- | --- |
| A | 序号 | 无 PDF 来源 | 沿用目标行预置序号或受控行规则。 |
| B | 学院 | 第 1 页封面“单位”；第 3 页基本情况 | 引文可保留字段标签，例如“单位 计算机科学与工程学院”；`value`、候选 `raw_text` 和写入 Excel 的值只能是空格后的“计算机科学与工程学院”。不从文件名猜测。 |
| C | 姓名 | 第 1 页封面“姓名”；第 3 页基本情况 | 两处结果不一致时不自行选值。 |
| D | 出生年月 | 第 3 页基本情况 | 保留来源的年月精度。 |
| E | 工作时间 | 第 3 页基本情况“参加工作时间” | 不与任现职时间混用；具体字值由 OCR 识别。 |
| F | 职称 | 第 3 页基本情况“何年何月取得专业技术职务” | 取现任职称，不把申报资格当现任职称。 |
| G | 职称取得时间 | 第 3 页与 F 同一职称行 | 与 F 配对。 |
| H | 学历 | 第 3 页学历表 | 按 Excel 标题选择学历，不将学位自动替换成学历。 |
| I | 学历取得时间 | 第 3 页与 H 同一学历行 | 与 H 配对。 |

服务端的本轮 PDF 覆盖集合只有 B–I。已核对的 25 页版式与 22 页 A4 版式均取第 1、3 页同一组冻结区域；其他页数、尺寸或不同版式不会自动扩大读取范围。Word 使用已归档完整正文中的真实 `source_unit_id`、逐列短引文与字符范围；扫描图片若未形成可核验文字则停止该文件。J–AA 无字段候选、无审批/资格判断；PDF 其他页面保持 `NOT_READ`。

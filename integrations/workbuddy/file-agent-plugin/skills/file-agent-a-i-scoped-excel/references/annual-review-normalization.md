# 考核优秀年度：OCR 标点的受限归一

只处理 `四位年份 + 单个连接字符 + 四位年份`，且两侧年份均以 `19` 或 `20` 开头。归一只改变中间的单个字符，不改年份数字、其他文字或其他标点。下表说明字符的候选语义；**脚本命中白名单不等于可以自动提交**，必须把每一处替换与原 PNG 对照，确认原图表达的是年度并列。

## 可归一为 `、` 的白名单

| 字符 | 理由 |
| --- | --- |
| `.` | OCR 可能把并列顿号识别为半角点；必须核对原图。 |
| `．` | OCR 可能把并列顿号识别为全角点；必须核对原图。 |
| `。` | OCR 可能把并列顿号识别为句号；必须核对原图。 |
| `·` | OCR 可能把并列顿号识别为中点；必须核对原图。 |
| `・` | OCR 可能把并列顿号识别为日文中点；必须核对原图。 |
| `｡` | OCR 可能把并列顿号识别为半角句号；必须核对原图。 |

## 永不归一的黑名单

| 字符 | 理由 |
| --- | --- |
| `-` | 常用于年度区间，不能推定每年均为优秀。 |
| `–` | 短连接号常表示区间。 |
| `—` | 长连接号常表示区间。 |
| `~` | 波浪连接号常表示区间。 |
| `～` | 全角波浪连接号常表示区间。 |
| `至` | 明确表示起止区间。 |
| `到` | 明确表示起止区间。 |
| `/` | 可能表示替代、分隔或范围，语义不确定。 |
| `／` | 全角斜杠同样语义不确定。 |
| `、` | 已是原文并列符，保留原样，无需再改。 |
| `，` | 已被后端正则接受为并列分隔符，保留原样。 |

脚本对命中的黑名单连接打印 `WARN` 并保持原文，其中 `-`、`至` 等尤其要防止被当成并列。白名单字符仅在原图确认是**并列分隔符**后才准写入归一文本。

## 对照例

| OCR 原文 | 归一后 | 归一前 `excellent_years()` | 归一后预期 |
| --- | --- | --- | --- |
| `2022.2024年度考核优秀；` | `2022、2024年度考核优秀；` | `[2024]` | `[2022, 2024]` |
| `2022．2024年度考核优秀；` | `2022、2024年度考核优秀；` | `[2024]` | `[2022, 2024]` |
| `2022-2024年度考核优秀；` | 原样保留 | `[2024]` | `[2024]` |
| `2022至2024年度考核优秀；` | 原样保留 | `[2024]` | `[2024]` |

不能直接放宽后端正则：如果把点号、横线或“至”等一并当作并列分隔符，`2022-2024` 这类区间就可能被解释成两个明确优秀年度。当前服务端有意只识别后一个年度；Skill 侧只修正人工核对过的点类 OCR 误识别，并保留原始片段与归一对照供审计。

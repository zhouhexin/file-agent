# 教学科研教授模板 A–AA 列来源路由

本表依据 25 页的《教师职务任职资格评审表（教授·教学科研型）》参考版式及其对应的
“教学科研教授”Excel 工作表建立。页码均为 **PDF 文件从 1 开始的物理页码**，不是页脚印刷页码。
它只规定优先查找的位置，不证明该页的事实、审批或资格条件已经成立；不得把目标 Excel
已有值或这份参考材料中的人名、年份、数值固定到其他申报人的任务中。

先核对真实上传 Excel 的工作表、A–AA 物理列、合并标题与目标 PDF 的表名/栏目。若结构不同，
不得机械套用这些页码；应先用低成本页面索引按栏目标题重新定位，再对定位页定向识别。

## 定向读取边界

1. 本表是 **候选页索引**。先从已缓存的同一 DocumentVersion 页面结果取证；需要 OCR 时，
   合并本轮所需列的页码，仅对缺失页/区域调用支持定向识别的宿主能力。页码变化时按栏目标题
   重新索引，并查看相邻续页，不得把“候选页未找到”当成“字段为空”。
2. N、O、P、Q–Y 是多事实或多条件字段。定向读取需同时包含所选条件的依赖页；只扫描表格主项
   不扫描它的审核意见或续页，不能产生 `SEALED_CONFIRMED` 或资格 `√`。
3. 若本轮要求 A–AA 全部列，本表候选页几乎覆盖整份 PDF，不能保证节省大量 OCR；主要优化是
   不重复扫描同页、优先复用缓存，并仅识别需要的栏目区域。宿主不支持页码/区域识别时，
   允许一次完整识别并复用，不得为追求速度漏读或编造证据。
